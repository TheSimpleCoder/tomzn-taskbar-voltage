# TomznReleVoltage

Утилита для Windows, отображающая текущее напряжение электросети в реальном времени прямо на панели задач (Taskbar) возле системного трея. Данные считываются с умного реле/автомата **TOMZN** (или любого совместимого устройства Tuya / Smart Life) по локальной сети через протокол Tuya Local API.

---

## ⚡ Особенности

- **Интеграция с панелью задач Windows**: виджет аккуратно позиционируется возле системного трея (`TrayNotifyWnd`) и визуально адаптируется под панель задач.
- **Аппаратный рендеринг (Direct2D / DirectWrite)**: четкий и плавный вывод текста без мерцания.
- **Цветовая индикация состояния сети**:
  - 🟢 **Зелёный (215 В – 229.9 В)** — нормальное напряжение сети.
  - 🟡 **Жёлто-оранжевый (200 В – 214.9 В и 230 В – 244.9 В)** — предупреждение (отклонение от нормы).
  - 🔴 **Красный (< 200 В или ≥ 245 В)** — критический уровень напряжения.
- **Работа по локальной сети**: не зависит от облака Tuya Cloud во время работы — запросы отправляются напрямую к реле через `tinytuya`.
- **Контекстное меню**: правый клик по виджету открывает меню для закрытия приложения.

---

## 🏗 Архитектура

Приложение состоит из двух компонентов:
1. **C++ (Win32, Direct2D, C++20)**:
   - Основное приложение (`TomznReleVoltage.exe`), создающее плавающее/закрепленное окно поверх панели задач.
   - Запускает Python-скрипт в скрытом процессе и считывает показания через анонимный пайп (`ReadFile` / `stdout`).
2. **Python (`rele.py`)**:
   - Использует библиотеку `tinytuya` (протокол 3.5).
   - Поддерживает постоянное TCP-соединение с реле, отправляет heartbeat и считывает DP (Data Point `6` для напряжения).
   - Выводит значения в формате `VOLTAGE:<число>` в стандартный поток вывода.

## 📋 Требования

- **ОС**: Windows 10 или Windows 11 (x64)
- **Среда сборки**: Visual Studio 2022 (с компонентами для разработки классических приложений на C++ и поддержкой C++20)
- **Интерпретатор**: Python 3.8+ (должен быть добавлен в системную переменную `PATH`)
- **Зависимости Python**:
  ```bash
  pip install tinytuya
  ```

## ⚙️ Настройка

Перед запуском укажите параметры вашего реле в файле `TomznReleVoltage/rele.py`:

```python
DEVICE_ID = "ваш_device_id"      # ID устройства в приложении Tuya / Smart Life
IP = "192.168.0.xxx"            # Локальный IP-адрес реле в вашей сети
LOCAL_KEY = "ваш_local_key"     # Локальный ключ шифрования (Local Key)
```

> [!TIP]
> Узнать `IP`, `DEVICE_ID` и `LOCAL_KEY` можно с помощью утилиты `tinytuya wizard` или через личный кабинет разработчика [Tuya IoT Platform](https://iot.tuya.com/).

## 🚀 Сборка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd TomznReleVoltage
   ```

2. Откройте решение `TomznReleVoltage.slnx` в **Visual Studio 2022**.

3. Выберите конфигурацию **Release** и платформу **x64**.

4. Соберите проект (`Ctrl + Shift + B` или `Сборка -> Собрать решение`).
   - Файл `rele.py` автоматически скопируется в выходную папку рядом с `TomznReleVoltage.exe`.

5. Запустите собранный `TomznReleVoltage.exe` (из каталога `x64\Release` или через Visual Studio `F5` / `Ctrl+F5`).
